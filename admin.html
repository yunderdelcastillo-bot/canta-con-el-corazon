4. Biblioteca de canciones

Tus canciones aparecerán aquí.
Importante: esta es una protección básica de la interfaz, no una protección segura del archivo. Los MP3 actuales usan URL pública y alguien con la URL directa podría acceder al audio. Para bloquear realmente la descarga hasta confirmar el pago, hay que configurar almacenamiento privado y enlaces firmados desde un servidor seguro.

Cómo se configura una sola vez

  1. Abre Supabase y crea un proyecto gratuito.
  2. Abre supabase-setup.sql, copia el contenido en SQL Editor y ejecútalo.
  3. Ejecuta el archivo supabase-private-storage.sql para convertir el bucket songs-audio en privado, límite 25 MB y tipo permitido audio/mpeg.
  4. En Authentication crea tu usuario administrador.
  5. Copia Project URL y la clave pública desde Project Settings → API y pégalas arriba.
La web ya queda preparada para conectarse, pero la subida permanente no funcionará hasta completar estos pasos en tu cuenta de Supabase. Los audios se sirven mediante enlaces firmados temporales. Configura también las variables de entorno del servidor privado en Render.
